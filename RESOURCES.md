# AWS Certified Data Engineer - Associate (DEA-C01) Resources

## Knowledge

- [AWS Certified Data Engineer - Associate Exam Guide](https://docs.aws.amazon.com/aws-certification/latest/data-engineer-associate-01/data-engineer-associate-01.html)
  Authoritative exam scope, domain weights, task statements, and in-scope AWS services. Use to decide what to study and how deeply.
- [DEA-C01 Exam Guide Revisions](https://docs.aws.amazon.com/aws-certification/latest/data-engineer-associate-01/dea-01-revisions.html)
  Official changes to the current exam guide. Use before every study-plan revision.
- [AWS Lambda event source mappings](https://docs.aws.amazon.com/lambda/latest/dg/invocation-eventsourcemapping.html)
  How Lambda reads and batches records from Kinesis, DynamoDB Streams, and queues. Use for streaming consumer questions.
- [Amazon Kinesis Data Streams with Lambda](https://docs.aws.amazon.com/lambda/latest/dg/services-kinesis-create.html)
  Configuration and behavior of a Lambda consumer for Kinesis Data Streams. Use for streaming ingestion and replay scenarios.
- [Gateway VPC endpoints for DynamoDB](https://docs.aws.amazon.com/vpc/latest/privatelink/vpc-endpoints-ddb.html)
  Private VPC access to DynamoDB without an internet gateway or NAT device. Use for network-isolation questions.
- [Amazon EFS security groups](https://docs.aws.amazon.com/efs/latest/ug/network-access.html)
  Required NFS connectivity rules for EFS mount targets. Use for Lambda, EC2, and EFS network scenarios.

## Wisdom (Communities)
